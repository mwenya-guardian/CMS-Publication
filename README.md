# Modular CMS Frontend

A React + Vite + Tailwind frontend for the CMS, integrating with the backend REST API.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview production build:
   ```bash
   npm run preview
   ```

Backend API base: `http://localhost:3001/api` (adjust in `services/api.ts` if needed).

## Tech Stack

- React 18, TypeScript 5, Vite 5
- Tailwind CSS, Headless UI, lucide-react
- axios, date-fns, jspdf, html2canvas
